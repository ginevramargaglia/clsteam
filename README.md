# CLS Monaco introduction

Mobile presentation: `index.html`. Printable version: `CLS-Monaco.pdf`.

To preview locally, run `python3 -m http.server 8000` in this directory and open the address in your browser.

For a public QR destination, publish the main branch root using GitHub Pages in repository Settings > Pages, or host index.html on the CLS website.
